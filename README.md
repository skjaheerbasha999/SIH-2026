# Smart & Fair Crop Procurement System

This repository is organized into `frontend` and `backend` services.

## Directory Structure

```
.
├── backend/
│   ├── package.json
│   └── server/
│       └── server.js
├── frontend/
│   ├── index.html
│   ├── package.json
│   ├── public/
│   ├── src/
│   └── vite.config.js
├── package.json
└── README.md
```

## Running the Application

### 1. Frontend
To run the React + Vite frontend application:
```bash
cd frontend
npm run dev
```
Or from the root directory:
```bash
npm run dev
```

### 2. Backend
To run the Node.js REST API backend server:
```bash
cd backend
npm start
```
Or from the root directory:
```bash
npm run server
```
